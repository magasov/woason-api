Условия использования программного интерфейса WOAson API

Редакция 1.0 · 20 августа 2026 г. · применяется к интерфейсу версии /api/v1. Настоящий документ не является публичной офертой в смысле статьи 437 Гражданского кодекса Российской Федерации.

1. Предмет

Настоящие условия определяют порядок доступа к программному интерфейсу платформы электронной торговли WOAson (далее — «API») для клиентских приложений покупателя, продавца и администратора. API предназначен для совершения операций с каталогом физических товаров, заказами, платежами и сообщениями в рамках платформы.

2. Доступ и аутентификация

Доступ к защищённым методам предоставляется по JSON Web Token (алгоритм HS256). Access-токен передаётся в заголовке Authorization: Bearer, срок действия — 15 минут. Обновление сессии выполняется refresh-токеном со сроком 7 суток; использованный refresh-токен погашается. Учётные данные, токены и ключи платёжного провайдера запрещено передавать третьим лицам и публиковать в клиентском коде.

3. Роли

Регистрация через API допускается только для ролей buyer и seller. Роль admin создаётся оператором платформы и не выдаётся через публичную регистрацию. Методы группы /admin/* доступны исключительно администратору. Методы группы /seller/* — продавцу либо администратору.

4. Персональные данные

При использовании API обрабатываются сведения, необходимые для исполнения договора купли-продажи и сопровождения заказа (идентификатор, имя, адрес электронной почты, номер телефона, адрес доставки). Обработка осуществляется в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных». Интегратор обязан обеспечивать сохранность токенов и не запрашивать избыточные данные.

5. Каталог и запрещённые категории

Витрина WOAson предназначена только для оборота физических товаров. Категории объявлений классифайда (в том числе автотранспорт, недвижимость, услуги, вакансии, туры) отклоняются API. Продавец несёт ответственность за достоверность описания, цену, наличие товара и законность предложения.

6. Платежи

Вебхук ЮKassa: POST https://api.woason.ru/api/v1/payments/yookassa/webhook. JWT клиента не требуется.

7. Загрузки

Допускаются только изображения форматов JPEG, PNG, WebP, GIF и AVIF, не более 10 МБ на файл. Файлы принимаются методом POST /api/v1/uploads (multipart). В карточки товаров, отзывы и профиль передаются полученные публичные URL, а не содержимое blob: или data:.

8. Ограничение ответственности

API предоставляется «как есть» в пределах работоспособности текущего инстанса. Оператор не гарантирует бесперебойность каналов связи, служб доставки и платёжного провайдера. Расчёт стоимости доставки носит справочный характер до момента оформления заказа.

9. Изменение интерфейса

Обратно несовместимые изменения публикуются в рамках новой мажорной версии префикса (/api/v2 и далее). Исправления в пределах v1 могут вноситься без предварительного уведомления, если они не меняют контракт успешных ответов.

10. Применимое право

К отношениям сторон применяется право Российской Федерации. Споры подлежат рассмотрению в соответствии с законодательством РФ по месту нахождения оператора платформы, если иное не установлено императивными нормами.
